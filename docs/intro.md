# Introducción a OtakuTrack

¡Bienvenido a la documentación oficial de **OtakuTrack**!

OtakuTrack es un sistema de gestión de colecciones de anime y manga diseñado para que los usuarios puedan llevar un registro detallado de sus series favoritas, episodios vistos y volúmenes leídos.

El software está construido siguiendo el patrón de arquitectura **Modelo-Vista-Controlador (MVC)**, utilizando **Java** como lenguaje principal, **JavaFX** para las interfaces gráficas y almacenamiento persistente relacional mediante **MySQL**.
